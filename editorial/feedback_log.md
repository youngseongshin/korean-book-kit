# 피드백 기록

의뢰인의 지적 → 원인 → 어떤 규칙·도구로 바꿨는지 적는다. 같은 지적이 다음 책에서 나오지 않게 하는 장치다.
규칙이면 `house_rules.md`에, 기계로 잡을 수 있으면 book.toml `[rules]`나 `engine/checks.py`에 옮긴다.

| # | 지적(요지) | 원인 | 대응 | 반영 위치 |
|---|---|---|---|---|
|   |   |   |   |   |

## 이 키트를 만든 책에서 쌓인 기록 (예시)

| 지적 | 원인 | 대응 | 반영 위치 |
|---|---|---|---|
| “~는가” 같은 제목·문장은 안 쓰는 표현이다 | 원문 제목의 직역 의문형 | 윤문 3회독, 의문형 제목 금지 | house_rules 1, passes/02, checks.py |
| 특정 독자에게 건넬 책이라 예민한 장은 내용을 바꿔 달라 | 특정 독자 | 다른 이야기로 교체, 금지어 자동 검사 | passes/01, book.toml `forbidden` |
| 단편마다 다른 작가 문체로 다채롭게 | 한 권 안의 단조로움 | 내용 궁합으로 작가 배정, 소설 문체로 다시 쓰기 | passes/03 |
| 고지문의 이야기 수가 틀렸다 | 구성을 바꾼 뒤 판권면 미갱신 | 최종 검수에 판권면 대조 | README ⑤ |
| ‘값을 묻다’는 어색하다 | 직역 비유 | 금지 정규식 | [rules].forbidden_regex |
| 노부부가 서로 이름으로 부르는 건 어색하다 | 호칭 감각 | 대사 속 배우자 이름 검사 | house_rules 3, dialogue_names |
| 90점짜리, 맛이 안 난다 | 반복 윤문으로 문장이 평균화 | 말맛 패스 | passes/04 |
| 메시지가 직접적이라 여운이 덜하다, 획일적이면 안 된다 | 모든 장이 교훈을 말로 정리 | 장의 절반에만 기법을 섞어 여운 | passes/04 |
| 노인을 서술에서 이름으로 부르는 게 어색하고 이름이 현대적이다 | 서술의 이름 지칭, 출생 연대와 안 맞는 이름 | 연대에 맞는 이름, 할머니·할아버지 서술 | house_rules 3, passes/06 |
