# 패스 06 · 호칭과 이름 정리

- **언제:** “할머니·할아버지를 이름으로 부르는 게 어색하다”, “이름이 너무 현대적이다” 같은 지적이 나왔을 때. 가능하면 원고 확정 단계에서 미리 한다.
- **검증:** `python3 bookkit.py check <project> polish <입력> <출력>` + 옛 이름 grep + book.toml `[rules].retired`에 옛 이름 등록 → `bookkit.py verify`가 PDF에서 잡는다.
- **방식:** 이야기 1편 = 서브에이전트 1개. 화자 표시(`Q|이름|`) 변경은 에이전트에게 맡기지 말고 메인 작업자가 스크립트로 한 번에 바꾼다(아래).

## 1. 이름 표 먼저 만든다
출생 연대에 맞는 이름으로. 예시(1940년대생 인물):

| 이야기 | 전 | 후 |
|---|---|---|
| 첫째 | 명희 / 정호 | 정숙 / 병철 |
| 둘째 | 강순영 / 박재문 | 강금순 / 박만수 |
| 셋째 | 정희, 혜란 / 도현 | 옥자, 숙희 / 종구 (영수·상길·미자는 유지) |

## 2. 지침 본문
{{house_rules}}

1. **서술(따옴표 밖)에서 노인을 이름만으로 부르지 않는다.** “명희는 웃었다” → “할머니는 웃었다”. 부부가 한 쌍이면 ‘할머니/할아버지’가 기본. 같은 말이 몰리면 주어 생략, ‘노인’, ‘영감’(할머니 시점), ‘안노인’, ‘두 분’, ‘노부부’로 변주. 이름은 꼭 필요할 때만 ‘○○ 할머니’로.
2. 이름이 남는 곳(등장인물 소개, 다른 사람이 부르는 대사, 여러 부부의 구분용 호칭)은 모두 새 이름으로.
3. 질문자는 ‘할머님/할아버님’. 여러 분이면 ‘영수 할아버님’.
4. 부부끼리 대사에서 이름 부르지 않기(기존 원칙 유지).
5. 조사를 받침에 맞게(“순영은”→“할머니는”, “재문이”→“할아버지가”). 어색해지면 문장째 다듬되 내용·말맛·여운은 건드리지 않는다.
6. `Q|이름|` 머리말은 그대로 둔다(메인 작업자가 따로 바꾼다).

이 이야기의 이름 표: {{name_table}}

## 3. 메인 작업자가 할 일
- 화자 표시는 원고 전체에서 `Q|옛이름|`을 `Q|새이름|`으로 일괄 교체한 뒤, `bookkit.py check`로 형식이 유지됐는지 확인한다.
- 화자 표시가 4자를 넘으면 매달린 이름 칸(3.3em)에 안 들어간다 → book.toml 해당 부에 `speakers = "inline"`.
- book.toml의 `cast`, `dialogue_names`, `[rules].retired`를 새 이름으로 갱신.
- 원고 밖의 이름도 찾는다: 판권면, 제사(epigraph) 출처, 뒤표지 인용 출처.
