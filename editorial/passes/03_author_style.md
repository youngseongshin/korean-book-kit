# 패스 03 · 작가 문체로 다시 쓰기

- **언제:** 여러 편을 한 권으로 묶을 때 편마다 목소리를 달리하고 싶을 때.
- **검증:** `python3 bookkit.py check <project> rewrite <입력> <출력>` → 장 구조 동일, 분량 1.00~1.45
- **방식:** 이야기 1편 = 서브에이전트 1개(동시 실행). 끝나면 별도 에이전트가 ‘대조 리뷰’(원고의 대사·장면이 빠짐없이 들어갔는지) → 패스 02 윤문 3회독.

## 작가 배정: ‘내용 궁합’으로
이야기의 형식·화자·정서에 맞는 작가를 고른다. 예시(노부부들과의 대화를 다섯 편으로 엮은 소설집):

| 이야기 | 작가 | 궁합 |
|---|---|---|
| 노부부의 긴 대담, 살림의 속엣말 | 박완서 | 생활 비유, 반어, 안사람의 속엣말 |
| 녹음기를 든 젊은 음향 편집자 | 무라카미 하루키 | 건조한 1인칭, 사물 목록, 노인들과의 온도 차 |
| 세 부부 녹취록 | 장강명 | 기록자 시점, 날것의 녹취, 사회적 디테일 |
| 동네 골목의 노부부 | 양귀자 | 다정한 화자, 수다, 골목 생활어 |
| 결혼을 앞둔 화자의 장중한 성찰 | 이문열 | 장중한 서술, 충청도 말, 서약 |
